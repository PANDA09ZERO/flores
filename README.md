# 🌸 Flowers - Proyecto HTML/CSS/JS

### Proyecto de flores animadas con CSS y JavaScript

## 🌺 Flores incluidas:
- **🌻 Amarillas** - Flores amarillas clásicas con animación suave
- **🌹 Rosas** - Rosas rojas con pétalos suaves y centro dorado
- **🪷 Lirios** - Lirios morados con tallo largo y espatas verdes

## 🎨 Estilos de interfaz:
- **🌼 Original** - Estilo original con diseño suave
- **🔥 Brutalismo Suave** - Estilo bold, geométrico con bordes redondeados, colores cálidos y tipografía heavy

## 🚀 Cómo usar:
1. Abre `index.html` en tu navegador
2. Selecciona el estilo de interfaz que prefieras
3. Haz clic en "TOUCH ME XD" para ver las flores animadas
4. En la página de flores, haz clic en el botón "🔥 Brutal" para alternar el estilo
